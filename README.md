# Willkomen bei "Data Science mit Python" Schuljahr 2026 / 2027 

## Inhalt des Kurses:

Thema 1: Python Grundlagen

Lerne die Grundlagen, ohne Vorkenntnisse, von Python kennen. Datentypen, Variablen, Zahlen, Listen, Funktionen, etc.

Thema 2: Data Science

In diesem Abschnitt lernst du, Daten nach Python einzulesen, zu filtern und grafisch auszuwerten.Du lernst mit Tools wie Numpy, Pandas, Matplotlib und Seaborn zu arbeiten.

Thema 3: Maschine Learning

Hier lernst du die unterschiedlichen Arten und Methoden von Machine Learning kennen und wie du diese für Lösungen verwendest (Sklearn, Lineare Regression, Entscheidungsbäume, Support Vector Machines, Overfitting vs. Underfitting)

Thema 4: Deep Learning / Neuronale Netze Mit Deep Learning lernst du die spezielle Methode des maschinellen Lernens und die dazugehörige Informationsverarbeitung. Du beginnst mit einem einzelnen Neuron hin zu einem Netz (Tensorflow, Keras)
